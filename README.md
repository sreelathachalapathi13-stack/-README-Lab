# GitHub Repository

## Aim
To create a GitHub repository and push a README file.

## Description
This experiment demonstrates creating a repository on GitHub and adding project documentation using a README file.

## Steps Performed
1. Logged into GitHub.
2. Created a new repository.
3. Added a README.md file.
4. Entered project information.
5. Committed the changes.

## Tools Used
- GitHub
- README Markdown

## Result
Successfully created a GitHub repository and pushed a README file.
